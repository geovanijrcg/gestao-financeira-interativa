# 💰 Gestão Financeira Interativa

Uma apresentação interativa sobre os principais conceitos da gestão financeira empresarial, desenvolvida para fins educacionais e apresentações escolares.

## 📚 Sobre o projeto

O projeto tem como objetivo explicar, de forma visual e prática, como funciona a gestão financeira de uma empresa, abordando receitas, despesas fixas, custos variáveis, investimentos e lucros.

A apresentação utiliza slides navegáveis, gráficos ilustrativos e uma calculadora interativa para demonstrar como os gastos influenciam os resultados de um negócio.

## ✨ Funcionalidades

- 📊 Apresentação em slides com navegação entre páginas.
- 💰 Explicação sobre receitas e faturamento.
- 🏢 Exemplos de despesas fixas.
- 📦 Exemplos de custos variáveis.
- 🚀 Conceitos de investimentos empresariais.
- 📈 Demonstração de lucro e margem de lucro.
- 🧮 Calculadora financeira interativa.
- 👥 Simulação de custos com funcionários contratados pelo regime CLT.
- 🎯 Quiz para testar os conhecimentos adquiridos.
- 🎨 Interface moderna, com animações e gráficos.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura do site.
- CSS3 — estilos, layout, responsividade e animações.
- JavaScript — navegação, cálculos e interatividade.

## 🧮 Calculadora financeira

A calculadora permite simular diferentes cenários empresariais com base em:

- Receita mensal.
- Custos variáveis.
- Despesas fixas.
- Outras despesas e impostos.
- Quantidade de funcionários CLT.
- Salário bruto mensal.
- Percentual estimado de encargos e provisões.

Os resultados são atualizados automaticamente conforme os valores informados.

> **Observação:** os valores e percentuais utilizados são ilustrativos e têm finalidade educacional. Os encargos trabalhistas e tributários reais variam conforme as características de cada empresa.

## 🎯 Objetivo educacional

Demonstrar a importância do planejamento financeiro, do controle de gastos e da análise dos resultados para uma boa gestão empresarial.

## 👨‍🎓 Público-alvo
